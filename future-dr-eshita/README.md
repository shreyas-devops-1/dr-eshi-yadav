# Future Dr. Eshita Yadav

A premium cinematic microsite for **Future Dr. Eshita Yadav** and the NEET 2027 journey. Built with HTML5, CSS3, vanilla JavaScript, GSAP, Typed.js, AOS, and canvas-confetti.

## Run locally

```bash
python3 -m http.server 8080 --directory future-dr-eshita
```

## Docker

```bash
cd future-dr-eshita/docker
docker compose up --build
```

Visit `http://localhost:8080`.
